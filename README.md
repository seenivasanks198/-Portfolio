## 🏗️ Portfolio Architecture

This portfolio is built as a **modern React + Vite** application with an enterprise-grade architecture:

```
📦 -Portfolio
├── 📄 index.html                 # Entry point
├── 📄 vite.config.ts             # Vite + TailwindCSS + React config
├── 📄 tsconfig.json              # TypeScript configuration
├── 📦 src/
│   ├── 📄 App.tsx                # Root app with Ant Design ConfigProvider
│   ├── 📄 main.tsx               # React DOM entry
│   ├── 📂 cms/                   # 📋 CMS-driven portfolio data (JSON)
│   │   ├── portfolio_data.json   # All resume & project data
│   │   └── settings.json         # Site configuration
│   ├── 📂 components/            # 🧩 19 reusable UI components
│   │   ├── Hero.tsx              # Animated hero section
│   │   ├── AboutSection.tsx      # About me details
│   │   ├── SkillsSection.tsx     # Interactive skills display
│   │   ├── ProjectsSection.tsx   # Project showcase grid
│   │   ├── ExperienceSection.tsx # Work experience timeline
│   │   ├── ContactSection.tsx    # Contact form with validation
│   │   ├── Navbar.tsx            # Navigation with scroll spy
│   │   ├── Footer.tsx            # Animated footer
│   │   ├── CommandPalette.tsx    # ⌘K command palette
│   │   ├── ThemeToggle.tsx       # Dark/Light mode switch
│   │   ├── LanguageSwitcher.tsx  # i18n language toggle
│   │   └── ...more
│   ├── 📂 config/                # i18n & app configuration
│   ├── 📂 layouts/               # Page layout wrappers
│   ├── 📂 pages/                 # Route page components
│   ├── 📂 store/                 # Zustand state management
│   ├── 📂 styles/                # Global CSS & theme tokens
│   └── 📂 types/                 # TypeScript type definitions
```

## ⚡ Quick Start

```bash
# Clone the repository
git clone https://github.com/seenivasanks198/-Portfolio.git
cd -Portfolio

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local
# Add your GEMINI_API_KEY to .env.local

# Start development server
npm run dev
```

> 🌐 App will be running at **`http://localhost:3000`**
